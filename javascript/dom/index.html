Document Object Model

The Document Object Model (DOM) is a programming interface for web documents. It represents the structure of a document as a tree of objects, allowing programming languages to manipulate the content, structure, and style of web pages.

In the DOM, each element, attribute, and piece of text is represented as a node. The DOM provides a way to access and modify these nodes using JavaScript.

For example, you can use the DOM to change the text of a heading, add new elements to a page, or respond to user events like clicks and key presses.

Here are some common DOM manipulation methods:

  • Properties:
    • document: Represents the entire HTML document.
    • document.body, document.head, document.title: Represent the body, head, and title of the document, respectively.
    • document.URL, document.location: Represent the URL of the document.
    • document.links, document.images, document.forms, document.scripts: Return collections of links, images, forms, and scripts in the document.
    • document.cookie: Refers to the cookies associated with the document.
  • Methods:
    • document.getElementById(id), document.getElementsByClassName(className), document.getElementsByTagName(tagName), document.getElementsByName(name): Retrieve elements by ID, class name, tag name, or name attribute.
    • document.querySelector(selector), document.querySelectorAll(selector): Retrieve elements using CSS selectors.
    • document.createElement(tagName), document.createTextNode(text): Create new elements or text nodes.
    • document.appendChild(newElement), document.removeChild(childElement), document.replaceChild(newElement, oldElement): Manipulate child elements in the document.
    • document.write(content), document.open(), document.close(): Write or manage document content.
  • Element Properties and Methods:
    • element.id: Represents the ID of the element.
    • element.setAttribute(name, value): Sets the value of an attribute on the element.
    • element.style.property = value: Changes the CSS style of the element.
    • element.addEventListener(event, function): Attaches an event handler to the element.
    • element.innerHTML, element.textContent: Set the HTML or text content of the element.
    • element.appendChild(newElement), element.removeChild(childElement): Add or remove child elements.
  • Class List Methods:
    • element.classList: Returns the class list of the element.
    • element.classList.add(className), element.classList.remove(className): Add or remove a class.
    • element.classList.toggle(className): Toggle a class on the element.
    • element.classList.contains(className): Check if the element has a specific class.
    • element.classList.replace(oldClass, newClass): Replace a class on the element.
    • element.classList.item(index): Get the class name at a specific index.
    • element.classList.length: Get the number of classes on the element.
